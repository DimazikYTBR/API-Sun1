# API Sun1 (S1)

A lightweight Python SDK and REST API bridge designed to convert numeric weights, scoring vectors, and latent embeddings into coherent text responses using **Dublikat AI**.

## Features

- **Direct Python Import**: Clean and quiet interface (`import api-sun1`).
- **Flexible Input**: Supports both dictionary-based parameter metrics and raw numerical arrays.
- **REST API Ready**: Built-in FastAPI server for remote microservice integration.
- **Model Downloader**: Streamlined weight fetching with clean console status notices.
